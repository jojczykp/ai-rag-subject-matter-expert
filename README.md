# AI Subject Matter Expert

Kotlin application based on Spring Boot.

## Requirements

- JDK 26
- Gradle 8.11+ or the Gradle Wrapper

## Run

```bash
gradle bootRun
```

## Test

```bash
gradle test
```

## Coverage

This project uses Kover for code coverage and enforces a minimum 80% coverage
threshold.

```bash
./gradlew koverVerify
./gradlew koverHtmlReport
```
